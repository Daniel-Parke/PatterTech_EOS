# WG-WEB-012: Literal imagery or generated fields?

status: active
review_by: 2027-07

## The question

When a brand's themes point at real-world imagery (space photography,
industrial scenes, nature), does the site use treated photographs or
generated abstractions (gradient fields, computed textures, drawn forms)?

## It depends on

- Whether the brand wants to be *placeable*: photography anchors the look to
  recognisable references; generated light stays unplaceable.
- Asset weight and rights: photographs cost kilobytes and licences;
  gradients cost bytes and nothing.
- Grading effort: photography must be colour-graded into the palette per
  image or the site fractures; generated fields are on-palette by
  construction.
- Whether a single literal moment would carry meaning a generated field
  cannot (a real product, a real place, a real team).

## Options

### A. Generated only
All atmosphere is computed: layered gradients, drawn strata, canvas systems,
tiny SVG turbulence. Fully on-palette, zero weight, infinitely consistent.

### B. Hybrid
Generated system plus one or two literal set pieces, heavily graded, each
individually justified in the lock-in.

### C. Photography-led
Treated imagery as the primary atmosphere. A different kind of site; demands
an art-direction budget and a grading standard, or it becomes a stock-photo
collage.

## Decision rule

Products, places and people that actually exist may earn B's literal
moments. Abstract themes (energy, physics, space-as-idea) take A: evoking a
nebula with computed light says "we build things"; pasting a NASA photograph
says "we downloaded things". C only with a real art-direction commitment.

## Default

A.

## Worked rulings

- **PatterTech Website v3 (2026-07)**: A, ruled explicitly by Daniel. The
  nebulae and pillars arrive as layered gradient strata on the interludes;
  the brand's light must be computed, like Cherenkov radiation itself, and
  the power should remain impossible to place.
