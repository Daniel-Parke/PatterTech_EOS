# CLAUDE.md — PatterTech Framework

This repo is documentation: the portable design-and-delivery framework for all
our projects. There is no build.

- Read `START.md` first; it sets the read order and the ground rules.
- `VISION.md` carries the standing mandate for growing this into an
  all-project kernel. Do not remove or dilute it.
- Doctrine changes require a wargame first (see START.md ground rules).
- Write in the house voice: plain, spoken, British spelling, no em-dashes, no
  exclamation marks, no AI clichés, no two-fragment antithesis.
