# TASKS

The venture's work surface at S scale, hand-kept because S runs
without the integrator tooling. Express work needs no row here; the
commit message is the whole record. A Standard task gets one row
while open and one log line when done.

## Open

Ordered, top first. A session takes the top item unless the launcher
names one. A row carries the intent, the mode and tier as routed, and
the owner when a session is on it. Nothing at the top may block on an
open question.
