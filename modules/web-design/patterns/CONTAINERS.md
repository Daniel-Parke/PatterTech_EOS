# Containers

Doctrine 5: there is no universal card. Pick the container by what the
content is. WG-003 argues the forks; this page is the anatomy.

## Decision table

| The content is... | Container | Never |
| --- | --- | --- |
| Parallel facts (features, services, principles, layers) | **Ledger** | icon-tile cards |
| Numbers with captions | **Plaque** | glowing stat cards |
| A self-contained thing (diagram, product, document, contact) | **Panel** | hover lift/sheen |
| Reading matter | plain prose | boxes |
| A pacing moment in a long read (quote, gallery, stat row) | **Interlude band** | same-surface slabs |
| The page's closing actions | **Colophon** | CTA slab |

## Ledger

A ruled editorial list. Each row: hairline top rule, mono index
(accent-tinted), display title, optional accent strap line, muted body,
right-hand mono meta. The list closes with a bottom rule. Rows with links are
fully clickable; hover brightens the rule and nudges the arrow. One or two
columns; width-agnostic.

## Plaque

Numbers as an instrument readout: values in the display face with
`tabular-nums`, hairline top and bottom rules, hairline column separators,
mono uppercase captions (with a small accent tick if the section carries an
accent). Values may count up once on first view; they never glow.

## Panel

The rare box: a quiet border on the first surface step, modest radius, an
optional short accent tick on the top edge. A Panel that is a link brightens
its border on hover; nothing moves except an arrow. If you are boxing a list
of parallel facts, you wanted a Ledger.

## Interlude band

A full-bleed band one surface step up, hairline top and bottom rules, content
constrained to the wide measure. Used to pace long reads (quotes, card
strips, stat rows). A warm-tinted variant exists and a piece gets at most one.
