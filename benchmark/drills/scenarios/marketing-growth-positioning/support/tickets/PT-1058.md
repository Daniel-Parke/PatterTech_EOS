# PT-1058  Gym plinth double booked

Practice: Carrfield Physio and Sports Injury, 4 practitioners
Raised: 2026-03-09 by Dev Mistry, practice manager
Closed: 2026-03-10

Two course sessions were put in the same slot and both needed the gym
plinth. Ossa should have refused the second one.

Cause: the second booking was created by an import from their old
shared spreadsheet, which does not go through `app/rooms.py` at all.
The clash check never ran.

Dev pointed out, fairly, that the spreadsheet is exactly what they left
behind because of this. Their old rule was a pencil line through the
plinth column and whoever wrote first won.

Resolution: import now runs the same allocation path. Backfilled a
check across their existing bookings and found one other clash in
April.
