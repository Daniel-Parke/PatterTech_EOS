# notecat

Bundles a folder of Markdown notes into one file. One script, no
dependencies, runs on any Python 3.

```
python cli.py --source notes --out-dir build
```

New here? Start with the [setup guide](docs/setup.md), then keep the
[reference](docs/reference.md) open while you work.

Changes are listed in [CHANGELOG.md](CHANGELOG.md).
