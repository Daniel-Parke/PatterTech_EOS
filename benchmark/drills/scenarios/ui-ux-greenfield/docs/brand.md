# Almsford Clinical brand notes

Extracted from the brand book Almsford sent over (PDF, 2019). This is
everything that applies to a screen.

## Colour

Two colours, no more.

| Name | Value | Use |
| --- | --- | --- |
| Almsford Navy | `#0E2A47` | Wordmark, headings, rules, primary action |
| White | `#FFFFFF` | Ground |

The book allows tints and shades of the navy where a single flat colour
will not carry a layout, and says nothing at all about a second hue.
Almsford's marketing team have asked twice that nothing warm appears
next to the wordmark, because the navy shifts green against it on their
own print stock.

## Typeface

**Almsford Grotesk**, all weights, drawn for them in 2016.

The licence is print only. There is no web licence and Almsford's
agency has quoted eleven months to get one, so the web tier needs
something else and needs to say what and why. Grotesque, not humanist,
and nothing with a calligraphic axis: the wordmark sits next to running
text on every screen and the mismatch shows.

## What the book does not cover

Interaction, states, error styling, data density, or anything about a
screen at all. The book is a print book. Anything below the wordmark is
ours to decide and ours to write down.
