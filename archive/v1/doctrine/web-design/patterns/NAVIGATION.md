# Navigation and chrome

## Header

Fixed, glass-on-scroll, one row: wordmark left, quiet text links centre
(active state as an underline, not a pill), a quiet bordered CTA right.
The header CTA never uses the loud treatment; if the chrome carries a brand
motif (a top hairline "line"), that is its one accent. Mobile: hamburger to a
full-width panel, links as rows, body scroll locked while open.

## Footer

The site's colophon: brand block with a one-line description and social
pills, link columns with mono uppercase column labels, then a mono meta block
(legal identity, registration, contact). The footer is where the annotation
voice signs the site.

## Content indices (hubs)

A hub with few entries styled as a card grid reads as an empty blog. Style it
as a **journal index** instead: numbered entries (oldest is No. 01, numbers
never change), mono date and imprint rail, display title, abstract, mono
type/length meta and an arrow, hairline rules between entries, whole row a
link. Filters are mono text tabs with counts, not pill chips. Two entries
then read as a curated record rather than a thin feed.

## Threading

Every page ends with one onward set (the colophon). Long-form pieces thread
each other ("Next: ..."), hubs point outward to the most related surface, and
no page dead-ends. Back links on detail pages return to the hub, top-left,
in the muted voice.
