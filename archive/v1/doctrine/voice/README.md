# Voice

The module that owns how the estate writes. Two organs: the voice law
(DOCTRINE.md, seven rules with the banned-list pattern) and the
register wargame (WG-VOX-001, who each surface talks to).

Status: populated at C2. The law was argued in practice across the
v0.1 web-design work and the EOS build before it was written down
here; eos_check E004 has enforced its mechanical rules since Phase A.

## Activation triggers

Any written surface a human reads: website copy, UI text,
documentation, emails, error messages. In practice every venture at
every scale; the module compiles into every seed and WG-VOX-001 walks
in every Session 0 (see inception/WALK_ORDER.md).

## What lives where

- The law and the banned-list pattern: `DOCTRINE.md`.
- The register fork: `wargames/WG-VOX-001-audience-register.md`.
- A venture's own banned list and register ruling: its lock-book and
  the voice reference it cites, never here.
