# CADENCE

The cadence rows live in `org/cadence.json`: id, frequency, last_run,
next_due and a procedure pointer into `org/PLAYBOOKS.md`. Three rows
ran under v2 rules on 2026-08-08 and count next_due from that run. The
rows that have never run still count from the v1.0.0 tag date,
2026-07-07. The v1 table is archived at
`archive/v1-final:org/CADENCE.md`.
