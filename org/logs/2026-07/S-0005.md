## Decisions taken

- The matrix supersedes ADR-0001 section 8's rough counts; S carries
  the operators guide and the compile report, so it is eight files with
  a six-file operating surface. Recorded in the matrix preamble.
- Three templates added beyond the queue item's letter (worklog, queue,
  NEXT) because the compile contract forbids seed files without
  template ancestry; the alternative was an authoring compiler.
- Scoreboard and practices are Genesis outputs, not seed files; the
  matrix lists the empty directories instead.
- Add-on rows whose file cell is prose (the restore-test cadence row)
  are not mechanically enforced; only path-like cells are. Noted in the
  matrix.
- The rulings row grammar is one line per ruling with middot
  separators, so the harvest and the seed check can parse rulings
  without a YAML library.
