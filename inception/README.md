# Inception

The Session 0 system: how a venture goes from an idea in Daniel's head
to a compiled seed pack a cold agent can build from.

Status: the full system lands in phases C and E (see `org/QUEUE.md`).
The shape, fixed by ADR-0001:

- `INCEPTION.md`: the master playbook, phases A to E. Interview, scale
  ruling, wargame walk, seed compile, gate.
- `INTERVIEW.md`: the intake protocol, with mandatory challenge steps:
  restate the venture and be corrected, name the three cheapest ways it
  dies, propose the strictly smaller version and have it explicitly
  rejected or adopted.
- `WALK_ORDER.md`: how to compile the venture's wargame walk from
  `doctrine/WARGAME_INDEX.md` filtered by triggered domains.
- `COMPILE.md`: the prune, fill, distil and report rules the seed
  compiler follows.
- `wargames/WG-EOS-001-venture-scale.md`: the scale ruling. Triggers:
  lifespan, server state or auth, money, personal or regulated data,
  ops burden, a second human. Default is the smallest scale that fits.
- `wargames/WG-EOS-002-repo-shape.md`: monorepo, polyrepo or adjacent
  site, with worked rulings from the estate.
