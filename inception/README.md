# Inception

The Session 0 system: how a venture goes from an idea in Daniel's head
to a compiled seed pack a cold agent can build from.

Status: complete (C1 and E1). The worked reference is
examples/venture-a-seed.md; drills run quarterly per PB-E07.

- `INCEPTION.md`: the master playbook, phases A to E. Interview, scale
  and shape, wargame walk, seed compile, gate.
- `INTERVIEW.md`: the intake protocol, thirteen questions and the three
  mandatory challenge steps: restate and be corrected, the three
  cheapest deaths, the strictly smaller version explicitly adopted or
  rejected.
- `WALK_ORDER.md`: how the venture's wargame walk is compiled from
  `doctrine/WARGAME_INDEX.md`, filtered by triggers, canonically
  ordered, budget-capped.
- `COMPILE.md`: the prune, fill, distil and report rules the seed
  compiler follows, and its never-list.
- `wargames/WG-EOS-001-venture-scale.md`: the scale ruling, six
  triggers, default the smallest scale that fits.
- `wargames/WG-EOS-002-repo-shape.md`: monorepo, polyrepo or adjacent,
  default the monorepo, worked rulings from the estate.
